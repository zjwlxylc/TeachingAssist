## 📝 测试用例

### 测试 1：学生端签到后自动引导

**目标**：验证学生首次签到后是否显示引导对话框

**前置条件**：
- 教师已创建课堂并开始
- 学生学号在课堂名单中

**测试步骤**：
1. 访问学生端：`http://localhost:5173`
2. 点击顶部导航"学生"
3. 输入课堂ID、学号、姓名
4. 点击"签到"

**预期结果**：
- ✅ 显示"签到成功"提示
- ✅ 自动弹出引导对话框，标题为"✅ 签到成功！"
- ✅ 显示4个选项：
  - 📢 查看课堂公告
  - ❓ 回答课堂问题
  - 💬 参与课堂互动
  - 📚 查看课堂作业
- ✅ 点击任一选项后跳转到对应模块
- ✅ 点击"稍后再说"关闭对话框

**注意**：
- 重复签到不会显示引导（只有首次签到）

### 测试 2：错误提示统一和翻译

**目标**：验证错误提示是否已翻译为中文

**测试场景 1：学号不在名单**
1. 学生端输入不存在的学号签到
2. 预期显示：`您不在课堂名单中，可以提交注册申请`（而非 `STUDENT_NOT_FOUND`）

**测试场景 2：网络错误模拟**
1. 关闭后端服务器
2. 学生端尝试签到
3. 预期显示：`网络连接失败，请检查网络后重试`（而非 `Network Error`）

**测试场景 3：断网发送互动消息**
1. 学生完成签到
2. 进入"课堂互动"模块

5. 预期显示：`网络连接已断开，请等待重新连接后再发送`

**验证点**：
- ✅ 所有错误消息都是中文
- ✅ 没有技术术语（如 Database、Network Error 等）
- ✅ 提示清晰易懂

## 💡 测试技巧

### 模拟网络断开
**Windows**：
- 方法1：禁用网络适配器
- 方法2：拔网线/关WiFi
- 方法3：浏览器开发者工具 → Network → Offline

**浏览器开发者工具**：
1. 按 F12 打开
2. Network 标签
3. 勾选 "Offline" 模拟断网
4. 取消勾选恢复连接

### 清除浏览器缓存
测试前建议清除缓存：
- Chrome：Ctrl + Shift + Delete
- 选择"缓存的图片和文件"
- 点击"清除数据"

### 查看控制台错误
测试时保持开发者工具打开：
- 按 F12
- Console 标签
- 查看是否有红色错误
