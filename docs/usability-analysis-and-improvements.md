# 教学辅助系统可用性分析与改进建议

> 生成时间：2026-07-12
> 版本：v0.1.0
> 范围：操作使用级别的不合理问题与改进方案

---

## 一、课堂互动模块问题与改进

### 1.1 课堂互动呈现不合理性

#### 问题描述
1. **消息流方向混乱**
   - 学生端和教师端的课堂互动消息使用气泡组件，但缺乏明确的"全班消息流"视觉提示
   - 学生发言和教师发言混在一起，未按时间线清晰排列
   - 缺少"谁在说话"的视觉层次

2. **发言审核流程不直观**
   - AI 审核拦截后，教师需要到单独的"待审核"区域查看
   - 待审核消息与已发布消息分离，教师难以理解上下文
   - 学生提交后得不到即时反馈（是已发布还是在审核中）

3. **互动开关状态不明显**
   - 学生端仅在输入框 disabled 时知道"已暂停发言"
   - 缺少顶部全局提示："教师已开启/暂停课堂互动"
   - 教师端开关按钮位置不够显眼

#### 改进建议

**A. 消息流优化**
```
┌─────────────────────────────────────┐
│  课堂互动（全班可见）                │
│  [开关] 学生发言已开启 | 待审核 (3)  │
├─────────────────────────────────────┤
│  [时间线视图]                        │
│  ┌─ 14:05 教师 ─────────────────┐   │
│  │ 今天讲解二叉树遍历，大家跟上  │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─ 14:06 张三（学生）──────────┐   │
│  │ 前序遍历的根节点在第一个？    │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─ 14:06 教师 ─────────────────┐   │
│  │ 正确！根-左-右的顺序          │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**B. 审核流程改进**
- 学生端：发送后立即显示"审核中⏳"状态标记
- 教师端：待审核消息以半透明形式插入时间线，点击可"放行"或"拒绝"
- 拒绝时可选择"仅教师可见"或"完全隐藏"

**C. 状态提示增强**
- 顶部固定状态条：
  ```
  📢 课堂互动：✅ 已开启 | ⏸ 已暂停 | 待审核 (3)
  ```
- 学生端暂停时全屏居中提示："教师已暂停互动发言，稍后开放"

---

### 1.2 互动功能缺失

#### 问题描述
1. **无法撤回或编辑**：学生发错内容无法撤回，教师也无法删除不当消息
2. **无法回复或引用**：无法针对某条消息进行回复，讨论缺乏上下文
3. **无表情或快捷反馈**：教师无法快速给学生留言点赞👍或标记❓
4. **无搜索和过滤**：消息多时难以查找特定内容

#### 改进建议
- **撤回**：学生 2 分钟内可撤回，教师随时可删除任意消息
- **回复引用**：点击消息显示"回复"按钮，新消息显示引用原文
- **快捷反应**：教师可对学生留言添加 👍❓💡 等 emoji 反应
- **搜索过滤**：顶部搜索框，可按学生姓名、关键词、时间段筛选

## 二、整体页面与模块呈现问题

### 2.1 学生端问题

#### 问题 1：左侧导航占用空间过大
**现状**：左侧栏固定 260px，在笔记本屏幕（1366x768）上占比过高
**改进**：
- 宽屏（>1440px）：260px
- 中屏（1024-1440px）：220px
- 窄屏（<1024px）：自动收起为图标栏（40px），点击展开

#### 问题 2：签到后的模块切换不直观
**现状**：签到成功后，仍停留在"签到"模块，学生不知道下一步做什么
**改进**：
- 签到成功后自动弹出引导提示：
  ```
  ✅ 签到成功！接下来你可以：
  · 查看课堂公告
  · 回答课堂问题
  · 参与课堂互动
  [关闭] [前往公告]
  ```
- 或自动跳转到"课堂公告"模块（如果有新公告）

#### 问题 3：课堂问答的答题区域混乱
**现状**：
- 单选/多选/填空/简答混在一个卡片里
- "提交答案"和"保存草稿"按钮并列，学生容易误操作
- 已提交后仍显示输入框（虽然 disabled），占用空间

**改进**：
```
┌─────────────────────────────────────┐
│ [单选题] 二叉树的前序遍历顺序是？   │
│                                     │
│ ○ A. 根-左-右                       │
│ ○ B. 左-根-右                       │
│ ○ C. 左-右-根                       │
│ ○ D. 根-右-左                       │
│                                     │
│ [你的选择: A]                       │
│                                     │
│ 📊 已提交 ✓ | 答对 ✓                │
│ 💬 AI 反馈：回答正确！前序遍历...   │
│                                     │
│ 截止时间：14:30 | 剩余 12 分钟      │
└─────────────────────────────────────┘

未提交时：
│ [提交答案] [保存草稿(可选)]         │
已提交后：
│ ✓ 已提交 (14:15)                    │
```

#### 问题 4：作业提交界面缺少进度提示
**现状**：提交多份作业时，不知道哪些已提交、哪些待提交
**改进**：
- 作业卡片顶部显示状态标签：
  ```
  📝 作业1：数据结构实验报告
  [未提交] | 截止：明天 18:00

  📝 作业2：二叉树代码实现
  [已提交 v2] | 得分：85/100
  ```

#### 问题 5：私信界面缺少"教师是否在线"提示
**改进**：顶部显示"🟢 教师在线"或"⚪ 教师离线"（基于教师端是否打开）

  ```

**现状**：每行 4 个按钮（补签/迟到/缺勤/请假），占用空间大

- 改为下拉菜单：
  ```
  [操作 ▼]
    · 补签
    · 标记迟到
    · 标记缺勤
    · 标记请假
  ```

#### 问题 4：AI 管理页面过于技术化
**现状**：Base URL、Model Name、HTTP Proxy 等术语对非技术教师不友好

- 预设模板：
  ```

#### 问题 5：问答统计数据密度过高
**现状**：统计表显示所有学生的详细作答，难以快速定位问题
**改进**：
- 增加汇总视图：
  ```
  📊 整体情况
  · 提交率：85% (34/40)
  · 正确率：72% (29/40)
  · 平均用时：3分 24秒

  · 6 人未提交
  · 11 人答错

  [查看详细列表]
  ```

## 三、全局操作问题

### 3.1 表单验证与错误提示

#### 问题描述
1. **缺少实时验证**：
   - 学号/姓名输入时不检查格式
   - 课程名称可以输入空格
   - 密码强度无提示

2. **错误提示位置不统一**：
   - 有的错误在顶部 Alert
   - 有的在表单字段下方
   - 有的在操作按钮旁边

3. **错误信息技术化**：
   - "ValueError: invalid literal for int()"
   - "Database integrity check failed"
   - 应该翻译为用户语言

#### 改进建议

**实时验证规则**：
```typescript
// 学号：8-12 位数字或字母
const STUDENT_ID_PATTERN = /^[A-Za-z0-9]{8,12}$/;

// 姓名：2-20 个中文或英文字符
const NAME_PATTERN = /^[一-龥A-Za-z\s]{2,20}$/;

// 课程名称：不允许纯空格
const COURSE_NAME_PATTERN = /\S+/;

// 密码：至少 8 位，包含字母和数字
const PASSWORD_PATTERN = /^(?=.*[A-Za-z])(?=.*\d).{8,}$/;
```

**统一错误提示组件**：
```tsx
<FormField
  label="学号"
  value={studentId}
  onChange={setStudentId}
  error={studentIdError}
  helperText={
    studentIdError
      ? "学号应为 8-12 位数字或字母"
      : "请输入您的学号"
  }
/>
```

**错误信息翻译**：
```typescript
const ERROR_MESSAGES: Record<string, string> = {
  "Database integrity check failed": "数据库完整性检查失败，请联系管理员",
  "Network timeout": "网络连接超时，请检查网络后重试",
  "Invalid credentials": "用户名或密码错误",
  "Student not found": "该学号不在课堂名单中，请检查后重试",
};
```

### 3.2 加载状态与反馈

#### 问题描述
1. **加载动画不一致**：
   - 有的用 CircularProgress
   - 有的用 "加载中..."文字
   - 有的无任何提示

2. **操作后无反馈**：
   - 点击"保存"按钮后，不知道是否成功
   - Excel 导入预览生成时间长，无进度条

3. **WebSocket 断线无提示**：
   - 学生端断网后，发送消息无反馈
   - 教师端断线不知道是否还能收到学生消息

#### 改进建议

**统一加载组件**：
```tsx
<LoadingButton
  loading={saving}
  loadingText="保存中..."
  onClick={handleSave}
>
  保存配置
</LoadingButton>

// 页面级加载
<PageLoader message="正在加载课堂数据..." />

// 操作级加载
<InlineLoader size="small" message="生成预览中..." />
```

**操作反馈Toast**：
```tsx
// 成功
showToast("success", "课程创建成功");

// 错误
showToast("error", "网络连接失败，请稍后重试");

// 警告
showToast("warning", "该学号已存在，将跳过导入");

// 信息
showToast("info", "AI 正在批阅作业，预计需要 2 分钟");
```

**WebSocket 状态指示器**：
```tsx
// 页面右上角
<ConnectionIndicator
  status={wsStatus}
  reconnecting={reconnecting}
/>

状态：
🟢 已连接
🟡 重新连接中...
🔴 连接已断开（点击重试）
```

---

### 3.3 数据展示与导航

#### 问题描述
1. **长列表无分页**：
   - 学生列表、签到记录、问答记录全部加载
   - 100+ 条记录时页面卡顿

2. **缺少面包屑导航**：
   - 在"课堂签到 > 签到统计 > 设备预警"时，不知道当前层级
   - 无法快速返回上一级

3. **数据无排序和筛选**：
   - 学生列表无法按姓名、学号排序
   - 签到记录无法筛选"仅显示缺勤"

#### 改进建议

**分页组件**：
```tsx
<DataTable
  data={students}
  columns={columns}
  pagination
  pageSize={20}
  sortable
  searchable
  searchFields={["student_id", "name"]}
/>
```

**面包屑导航**：
```tsx
<Breadcrumbs>
  <Link to="/teacher">教师工作台</Link>
  <Link to="/teacher?section=classroom">课堂签到</Link>
  <Typography>签到统计</Typography>
</Breadcrumbs>
```

**筛选和排序**：
```tsx
// 签到记录
<FilterBar>
  <Select value={statusFilter} onChange={setStatusFilter}>
    <Option value="all">全部</Option>
    <Option value="normal">已签到</Option>
    <Option value="absent">缺勤</Option>
    <Option value="late">迟到</Option>
    <Option value="leave">请假</Option>
  </Select>

  <Select value={sortBy} onChange={setSortBy}>
    <Option value="time">按时间</Option>
    <Option value="name">按姓名</Option>
    <Option value="status">按状态</Option>
  </Select>
</FilterBar>
```

## 四、具体模块优化建议

### 4.1 课前准备模块

**问题**：三步流程（选课程→勾选班级→创建课堂）分散在三个区域，关联不明显

**改进**：步骤指示器
```
┌──────────────────────────────────────────┐
│ 课前准备向导                              │
│ ① 选择课程 → ② 选择班级 → ③ 创建课堂    │
│   ✓ 已完成     进行中        待完成      │
├──────────────────────────────────────────┤
│ [当前步骤内容]                            │
│                                          │
│ [上一步] [下一步]                        │
└──────────────────────────────────────────┘
```

---

### 4.2 班级管理模块

**问题**：Excel 导入流程复杂，字段映射对新手不友好

**改进**：
1. **提供示例模板下载**
   ```
   [下载 Excel 模板]
   模板包含标准字段：学号、姓名、班级、专业、年级
   ```

2. **智能映射预设**
   ```
   检测到表头：
   · "学号" → 自动映射为 student_id
   · "姓名" → 自动映射为 name
   · "班级名称" → 自动映射为 class_name

   [一键应用智能映射]
   ```

3. **导入进度可视化**
   ```
   正在导入... 45/100 (45%)
   [██████████░░░░░░░░░░]
   预计剩余时间：15 秒
   ```

### 4.3 课堂问答模块

**问题**：
- 题目编辑界面各题型切换时，选项会丢失
- 无法批量导入题目
- 简答题 AI 反馈等待时间长，无进度提示

**改进**：
1. **题型切换保护**
   ```
   您正在从"单选题"切换到"填空题"
   当前已填写的选项将会丢失，确定要切换吗？
   [取消] [确认切换]
   ```

2. **批量导入支持**
   ```
   [从 Excel 导入题目]
   支持格式：
   · 列 A：题型（单选/多选/判断/填空/简答）
   · 列 B：题干
   · 列 C：选项（单选/多选用 | 分隔）
   · 列 D：正确答案
   ```

3. **AI 批阅进度**
   ```
   📝 正在批阅简答题...
   已完成：12/35 (34%)
   预计剩余时间：约 2 分钟

   [查看已完成的反馈]
   ```

### 4.4 作业模块

**问题**：
- 教师无法预览学生提交的文件（仅显示文件名）
- 作业批量评分不便
- 学生无法看到作业评分标准

**改进**：
1. **文件预览**
   ```
   学生提交：
   · report.pdf (2.3 MB) [预览] [下载]
   · code.zip (1.1 MB) [下载]

   ```

2. **批量评分**
   ```
   [批量操作]
   · 选中的 12 份作业
   · 统一评分：[85] 分
   · 统一反馈：代码规范，逻辑清晰

   [应用到选中项]
   ```

3. **评分标准前置**
   ```
   学生端作业卡片显示：
   📋 评分标准：
   · 代码正确性：40%
   · 代码规范：30%
   · 注释完整性：20%
   · 按时提交：10%
   ```

## 九、总结

本项目在功能完整性和技术架构上已达到较高水平，主要问题集中在：

1. **用户界面反馈不足**：缺少加载状态、操作结果、连接状态等关键反馈
2. **信息层次不清晰**：消息流、数据列表、操作按钮缺乏视觉层次
3. **交互流程可优化**：部分多步操作缺少引导，容易迷失
4. **错误处理粗糙**：技术错误直接暴露给用户，缺少友好翻译

建议按照优先级逐步改进，优先解决高优先级问题以显著提升用户体验。
