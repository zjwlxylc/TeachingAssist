# 分班签到控制（r5）

同一课堂接待不同班级时，在“课堂签到”中点击“继续签到”：之后首次签到记正常，直到教师点击“暂停签到”。暂停后仍可签到，但记迟到；下一班点击继续即可。已签到学生的记录保持原样，不会因重复签到或暂停/继续被重置。

只有进行中的课堂可以操作；暂停不会结束课堂、生成缺勤或清空签到。所有班级完成后才点击“结束课堂”。如果设置了课堂结束时间，原有到时自动结束仍有效；跨天共用课堂应不填写结束时间。

新增 migration 021，将控制状态保存在数据库；已有课堂默认保留原时间判定，教师首次暂停/继续后进入手动控制。教师鉴权的 PUT `/api/v1/classroom/sessions/{id}/sign-in-mode` 接受 open / paused。审批后的自动签到共用判定规则。

验证：54 项 unittest 通过，TypeScript/Vite 构建通过；隔离浏览器实际点击暂停/继续并核对提示；独立打包 EXE 验证暂停/继续/暂停得到 late/normal/late，21 个迁移和数据库完整性通过。隔离冒烟检查 24/24 通过。
