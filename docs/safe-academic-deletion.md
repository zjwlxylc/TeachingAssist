# 班级与课堂安全删除

适用范围：源码版的班级管理、课堂签到；用于清理误建、不再需要或测试用的内容，不依赖名称中是否包含“测试”。

## 使用

1. 在班级列表或课堂签到列表中搜索目标，点击该行的“删除”。
2. 查看目标编号、名称及受影响记录数量。
3. 完整输入名称，点击“确认删除”。删除不可撤销；取消或关闭弹窗不会修改数据。

班级仍关联课堂时，弹窗列出课堂编号、课程与标题，并提供“前往课堂签到管理”。按依赖顺序处理不再需要的课堂，再删除班级；有用的课堂应保留，不能为清理班级而误删。

## 删除边界

| 对象 | 可删除条件 | 删除范围 | 保留内容 |
| --- | --- | --- | --- |
| 课堂 | 未开始或已结束 | 本课堂关联、签到、题目及答案、作业及提交、评估、互动、注册申请、设备记录、恢复记录、登录令牌、本课堂 AI 任务与安全记录、作业附件 | 课程、班级、学生名单、其他课堂、全局私信 |
| 班级 | 没有课堂关联，且班级内学生无课堂历史记录或注册申请 | 班级、全部学生名单（含停用学生）、课程关联、该班学生收发的私信、残留登录令牌与互动审核记录 | 课程、其他班级及其学生与课堂、全局导入作业历史 |

正在进行的课堂禁止删除；暂停签到仍是进行中状态。班级删除不会自动删除关联课堂，尤其避免影响多班共同授课的课堂。学生转班后留下的其他课堂记录同样阻止删除其当前班级。

删除真实数据必须由教师在界面选择并确认，本次开发验证只操作隔离数据库。

## 实现与保护

- 四个接口：`GET /academic/classes/{id}/deletion-preview`、`DELETE /academic/classes/{id}`，以及对应 `sessions` 接口。全部使用教师认证和统一响应格式。
- 预览在同一数据库读事务中计算影响，摘要绑定对象与所有相关记录。删除在 `BEGIN IMMEDIATE` 写事务内重新检查；数据变化、名称错误或状态不允许均返回 409。
- 复用现有外键级联；显式清理没有外键的令牌、审核记录及多态 AI 记录。事务失败时所有数据库删除一同回滚。
- 登录令牌及审核日志的插入同时检查课堂和学生仍存在，避免迟到请求在删除后重新产生孤立记录。
- 数据库提交成功后清理作业附件，只删除配置上传目录中不再被其他附件引用的文件。共享、越界、被占用的文件保留并提示数量，不把数据库删除误报为失败。
- 删除后刷新列表、课程关联和已选对象；搜索仅影响管理列表，不影响其他页面的课堂选项。
- 不重建数据库、不改变现有表结构，不自动删除运行库中的任何班级或课堂。

## 验证

- `tests/test_academic_deletion.py`：10 项隔离数据库测试，覆盖鉴权、名称确认、活动课堂保护、预览过期、关联班级与转班历史保护、名单和私信清理、级联清理、附件范围和共享保护、事务回滚、迟到写入。
- `python -m unittest discover -s tests`：74 项通过。
- `npm run build`：通过；现有打包体积警告仍存在。
- 浏览器检查：班级和课堂删除预览、名称匹配启用确认、关联课堂阻止原因、跳转入口、活动课堂保护、取消操作与弹窗布局。最终数据库删除由 API 集成测试验证。
