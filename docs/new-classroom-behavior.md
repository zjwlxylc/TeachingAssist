# C 教室没有数据时的行为说明

## 📋 问题：C 教室里面没有数据的话，它默认的是拷贝 U 盘里面最新一期的数据吗？

## ❌ 答案：不是！

**C 教室没有数据时，系统会自动创建一个全新的空数据库，而不会自动从 U 盘恢复备份。**

---

## 🔍 实际行为

### 启动流程

当你在 C 教室（新教室）启动程序时：

1. **检查 C 盘数据库**：
   ```
   检查文件：C:\TeachingAssist\data\teaching_assist.db
   ```

2. **数据库不存在**：
   - 系统自动创建新的空数据库文件
   - 应用所有 20 个迁移（创建表结构）
   - **不会**自动从 U 盘恢复备份

3. **结果**：
   ```
   C:\TeachingAssist\data\teaching_assist.db (全新的空数据库)
   - 有完整的表结构
   - 没有任何课程、学生、课堂数据
   - 需要重新导入学生或手动恢复备份
   ```

## 📊 完整场景说明

### 场景 1：第一次在 C 教室使用

**状态**：
- C 盘：无数据
- U 盘：有 A 教室和 B 教室的备份

**启动后**：
```
C:\TeachingAssist\
└── data\
    └── teaching_assist.db  ← 新创建的空数据库
```

**你会看到**：
- ✅ 系统正常启动
- ✅ 可以登录
- ❌ 没有任何课程
- ❌ 没有任何学生
- ❌ 没有历史课堂记录

**这是一个全新的环境！**

### 场景 2：想使用 A 教室的数据

**方法**：手动恢复备份

1. 登录系统
2. 进入"系统管理" → "数据备份"
3. 点击"恢复备份"
4. 选择 U 盘备份：
   ```
   可恢复的备份：
   [ ] C:\TeachingAssist\backups\... (本地备份 - 空的)
   [ ] E:\backup\teaching_assist_manual_20260713_100000_abc123.db (A 教室)
   [x] E:\backup\teaching_assist_manual_20260713_150000_def456.db (B 教室) ← 选择这个
   ```
5. 点击"恢复"
6. 系统自动：
   - 备份当前数据库（防止误操作）
   - 用选定的备份替换当前数据库
   - 重启服务

**恢复后**：
- C 教室现在有了 B 教室的所有数据
- 课程、学生、历史课堂都在

## ⚠️ 关键点

### 1. 不会自动恢复

**系统绝不会自动从 U 盘恢复数据**，原因：
- 安全性：防止意外覆盖现有数据
- 灵活性：你可能就是想要一个新环境
- 明确性：恢复数据是重要操作，需要用户明确确认

### 2. 手动恢复的步骤

**恢复备份必须通过以下步骤**：
1. 登录系统
2. 进入"数据备份"功能
3. 选择要恢复的备份文件
4. 确认恢复

**完全是手动操作，没有自动化。**

### 3. 恢复前会自动备份

**安全机制**：
- 恢复前，系统会自动备份当前数据库
- 备份文件名：`before_restore_{timestamp}.db`
- 保存位置：`C:\TeachingAssist\backups\`
- 即使恢复错了，也可以回退

## 💡 使用建议

### 建议 1：固定教室使用

**如果每次都在同一个教室**：
- 不需要恢复备份
- 数据自动累积在 C 盘
- U 盘备份只是保险

### 建议 2：跨教室使用数据

**如果需要在多个教室使用相同的数据**：

**方法 A：每次手动恢复**
1. 到新教室启动程序
2. 手动恢复上次备份
3. 继续使用

**方法 B：主教室 + 同步（推荐）**
1. 选定一个主教室（如 A 教室）
2. 主要在 A 教室工作，数据在 A 教室累积
3. 偶尔去 B 教室时：
   - 先在 A 教室备份
   - 到 B 教室恢复 A 的备份
   - 在 B 教室工作
   - 结束后在 B 教室备份
   - 回到 A 教室恢复 B 的备份

**方法 C：每个教室独立（推荐）**
1. 每个教室有独立的数据
2. A 教室：软件 101 的学生
3. B 教室：数据库 201 的学生
4. 互不干扰

### 建议 3：新学期开始

**新学期第一次使用**：
- 直接使用空数据库
- 导入新学期的学生名单
- 创建新学期的课程

**不需要恢复上学期的备份**，除非：
- 需要查看上学期的历史记录
- 需要延续上学期的课程

## 🎯 总结

### 问题答案

**C 教室没有数据时**：
- ❌ 不会自动拷贝 U 盘最新备份
- ✅ 会创建全新的空数据库
- ✅ 你可以手动选择恢复哪个备份（如果需要）

### 设计理念

**为什么不自动恢复？**
1. **安全**：防止意外覆盖
2. **灵活**：有些场景就是需要新环境
3. **明确**：数据恢复是重要操作，必须用户确认

### 实际操作

**如果想使用其他教室的数据**：
1. 登录系统
2. 进入"数据备份" → "恢复备份"
3. 选择 U 盘上的备份文件
4. 点击"恢复"

**3 步完成，简单明了。**
