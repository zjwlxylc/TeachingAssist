# v0.4.5 课堂管理与启动改进

教师端“班级管理”和“课堂签到”新增搜索与安全删除。删除前显示关联数量，需输入完整名称确认；班级关联课堂或学生仍有课堂记录时阻止删除，进行中的课堂也不能删除。删除课堂会清理该课堂签到、问答、作业、互动、评估、注册申请和相关附件，保留课程、班级、学生名单及其他课堂。详细规则见 [班级与课堂安全删除](../safe-academic-deletion.md)。

仓库根目录新增 `开始上课.bat`，从源码构建前端并启动服务；旧 `start_dev.bat` 和 `fix_and_start.bat` 已移除。此前尚未打包的数据库更新简化和 AI Key 明文数据库保存修正也包含在本版中。

交付包为 `TeachingAssist-Classroom-r10.zip`，解压后双击“开始上课.bat”。程序与数据库分离；教学数据继续位于教师机 `C:\TeachingAssist\data\teaching_assist.db`。升级前先关闭旧版服务。压缩包不含数据库或 AI Key。

验证：74 项后端测试通过，其中 10 项覆盖本次删除场景；前端生产构建通过；隔离数据库的浏览器检查覆盖搜索、删除影响预览、名称确认、关联课堂阻止和进行中课堂阻止。真实机房跨机器访问仍需现场确认。
