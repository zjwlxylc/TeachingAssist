# v0.4.4 机房试点修复

本版修复了班级创建请求校验失败、学习评估 CSV 下载失败、备份恢复未处理 SQLite WAL、作业附件无法下载等课堂试点问题。学生访问地址改为自动采用当前物理网卡和实际端口，启动器增加仅限本地子网的程序防火墙规则检查。

教师端现在能持续看到待审批注册申请。同一课堂可手动“暂停签到 / 继续签到”：暂停后新签到记迟到，继续后新签到记正常；原有出勤记录保持不变。数据库迁移 `021_manual_sign_in.sql` 保存控制状态；已有课堂首次手动操作前仍按原来的时间规则判定。

学生端刷新后会用仍有效的学生令牌恢复身份，退出按钮撤销令牌。课堂互动消息会实时显示，双方每 5 秒补查一次；学生发送后立即看到自己的消息。

验证：55 项单元及流程测试、24 项隔离冒烟检查、前端构建通过；隔离浏览器验证刷新恢复、退出、双向互动和分班签到；Windows 免安装 EXE 验证迁移、签到状态、会话恢复/撤销、附件和备份。机房跨机器试运行仍需在实际网络中确认。

本地交付物为 `TeachingAssist-Classroom-r6.zip`。仓库的 `.gitignore` 不跟踪打包 ZIP 和 EXE，Git tag 标记的是经验证的源码。升级时先关闭旧服务，再运行新版启动器，教学数据库仍位于教师机本地。
