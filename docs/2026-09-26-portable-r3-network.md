# r3 网络访问地址修复

本版保留 r2 全部修复，新增：

- Windows 上读取真实网卡名称、连接状态和默认网关，优先推荐非虚拟网卡。
- 忽略不再属于本机的已保存 IP。
- EXE 启动后，访问地址始终使用实际监听端口，旧保存端口不再覆盖它。
- 网卡候选列表的选中标记与实际选择保持一致。

验证：49 项自动测试通过，包括 3 项新增网络回归。最终 EXE 检查见 BUILD-INFO.json。
这些检查不能证明另一台机房电脑已经恢复访问；仍须在那台电脑确认地址、监听状态和网络连接。

## 现场排查

1. 在运行 TeachingAssist.exe 的电脑上双击 start_teaching_assist.bat，使用启动器实际打开的本机地址进入教师端。
2. 如果显示端口为 8081，在这台电脑测试 http://127.0.0.1:8081/teacher；若打不开，再检查启动器打开的端口和服务窗口中的启动错误。
3. 运行 ipconfig，找到实际连接机房的“以太网”或“WLAN”IPv4，忽略 VPN、VMware、WSL 等虚拟适配器。也可在软件“系统与备份”选择实际网卡。
4. 学生使用 http://教师机实际IPv4:实际端口/student；学生电脑不能使用 127.0.0.1 访问教师机。
5. 本机回环能打开而学生打不开时，再检查教师机防火墙、两台机器是否在同一可互访网络，以及机房是否启用终端隔离。不要关闭整个防火墙。

U 盘放置本身不会决定访问地址。运行数据库仍位于教师机 C:\TeachingAssist。升级前先停止旧服务，再运行新包；否则启动器会继续打开旧服务。
