# 部署检查清单

## 1. 教师机环境

- Windows 10 或以上版本。
- 教师机与学生机处于同一局域网。
- 教师机防火墙允许所选端口入站访问。
- `C:\TeachingAssist` 可写。
- U 盘空间充足，建议至少预留 2 GB。

## 2. 部署包检查

- 存在 `start_teaching_assist.bat`。
- PyInstaller 打包模式下存在 `TeachingAssist.exe`。
- 存在 `config/default.yaml`。
- 存在 `frontend/dist/index.html`。
- 存在教师手册、部署清单、故障排查手册和试点反馈模板。

## 3. 首次启动检查

- 双击启动器后后端无异常退出。
- 教师端可访问 `http://127.0.0.1:8080`。
- 健康检查接口返回正常。
- 启动检查显示数据库完整性为 `ok`。
- 首次教师密码设置成功。

## 4. 局域网访问检查

- 教师端“访问地址”显示可用局域网 IP。
- 学生机可访问教师端显示的地址。
- 学生机可打开学生端页面。
- 端口被占用时，系统可切换到 8081 或 8888。

## 5. 课堂链路检查

- 创建课程、班级和课堂成功。
- Excel 学生名单导入成功。
- 开始课堂后学生可签到。
- 公告可实时送达学生端。
- 问题发布和学生答题正常。
- 作业发布和学生提交正常。
- 课堂结束后缺勤标记和备份正常。

## 6. AI 与降级检查

- 未配置 AI Key 时系统显示基础模式。
- 基础模式下签到、答题、作业和统计可用。
- 配置 AI Provider 后手动自检可返回结果。
- 内容安全测试可记录并返回处理结果。

## 7. 备份检查

- 本地备份目录可写。
- U 盘备份目录可写。
- 手动备份成功。
- 备份文件大小合理。
- 恢复前已确认目标备份文件来源。
