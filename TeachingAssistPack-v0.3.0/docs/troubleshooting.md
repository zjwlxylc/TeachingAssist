# 故障排查手册

## 1. 教师端打不开

- 确认 `start_teaching_assist.bat` 已启动。
- 依次访问 `http://127.0.0.1:8080`、`http://127.0.0.1:8081`、`http://127.0.0.1:8888`。
- 查看 `C:\TeachingAssist\logs\teaching_assist.log`。
- 若提示端口占用，关闭占用程序或使用备用端口。

## 2. 学生机无法访问

- 确认学生机与教师机在同一局域网。
- 使用教师端“访问地址”显示的 IP，不要使用 `127.0.0.1`。
- 检查 Windows 防火墙是否允许对应端口。
- 在学生机浏览器中直接访问 `http://教师机IP:端口`。

## 3. 数据库异常

- 打开教师端启动检查，确认完整性检查结果。
- 查看 `C:\TeachingAssist\data\teaching_assist.db` 是否存在。
- 查看 `C:\TeachingAssist\backups` 是否有最近备份。
- 恢复备份前先备份当前数据库。

## 4. Excel 导入失败

- 确认文件为 `.xlsx` 或 `.xls`。
- 检查表头是否包含学号和姓名。
- 使用字段映射或 AI 映射建议重新匹配。
- 导出错误报告，按行修正后重新上传。

## 5. 公告或问题未实时送达

- 学生端刷新页面后会补拉历史公告和问题。
- 检查浏览器是否拦截 WebSocket。
- 确认教师机端口可被学生机访问。
- 网络短暂中断时，学生端会尝试重连。

## 6. 学生提交失败

- 确认课堂仍处于活动状态。
- 确认学号和姓名与导入名单一致。
- 文本类答题和作业在断线时会缓存，重连后自动重发。
- 带附件作业无法离线缓存，需恢复网络后重新提交。

## 7. AI 功能不可用

- 检查 Provider 是否启用。
- 检查 API Key 是否已配置。
- 检查 base_url、模型名和代理配置。
- 手动触发 AI 自检查看错误信息。
- AI 不可用时系统会进入基础模式，核心课堂流程不受影响。

## 8. 备份到 U 盘失败

- 确认 U 盘未被拔出。
- 确认 `config/local.yaml` 的 `storage.removable_root` 指向正确盘符。
- 确认 U 盘可写且空间充足。
- 本地备份仍会保存在 `C:\TeachingAssist\backups`。
