# 教师使用手册

## 1. 启动系统

1. 将部署包放在教师机或 U 盘目录中。
2. 双击 `start_teaching_assist.bat`。
3. 浏览器打开 `http://127.0.0.1:8080`。
4. 如果 8080 被占用，依次尝试 `http://127.0.0.1:8081`、`http://127.0.0.1:8888`。

首次使用时需设置教师端密码。后续进入教师工作台需要使用该密码登录。

## 2. 课前准备

1. 创建课程和班级。
2. 关联课程与班级。
3. 创建课堂，填写课次、课堂标题和计划时间。
4. 上传学生 Excel 名单。
5. 使用字段映射或 AI 映射建议完成表头匹配。
6. 预览导入结果，确认无错误后导入。

如发现重复学号，可选择增量合并、覆盖更新或跳过重复。导入错误可导出 CSV 报告。

## 3. 课堂运行

1. 在“课堂运行与签到”中点击开始课堂。
2. 将课堂 ID 或访问地址告知学生。
3. 学生使用浏览器进入学生端，填写课堂 ID、学号和姓名完成签到。
4. 教师可实时查看签到统计。
5. 如需补签或修改状态，在签到统计表中操作并填写调整原因。
6. 课堂结束后点击结束，系统会标记缺勤并触发备份。

## 4. 公告、问答和作业

- 公告：选择课堂后发布，在线学生会实时收到。
- 问答：选择题型、填写题干和答案后发布；系统自动统计提交数、正确率、选项分布和典型答案。
- 作业：填写标题、说明、截止时间和评分标准后发布；学生可提交文本和附件，教师可查看提交列表。

AI 可用时，简答题反馈、作业批阅和学习建议会调用已配置 Provider；AI 不可用时基础课堂功能继续可用。

## 5. 学习评估

1. 在“学习评估与恢复”中选择课堂。
2. 根据需要调整出勤、问答、作业、公告和活跃度权重。
3. 点击临时评估或最终评估。
4. 查看平均分、等级分布、异常预警和学生明细。
5. 可导出 CSV 报告。

学生端可在教师生成评估后查看个人学习反馈。

## 6. 备份与恢复

- 系统默认使用 `C:\TeachingAssist\data\teaching_assist.db` 作为运行数据库。
- 手动备份入口在教师端“数据库备份”面板。
- 系统也会定时备份，并在课堂结束后自动备份。
- 若配置了 U 盘目录，会同时备份到 U 盘 `backup` 目录。

恢复备份前系统会生成安全副本。恢复后建议重启服务并检查健康状态。
